# KHORA map plates

Background images for KHORA map animations.

Satellite imagery: Sentinel-2 cloudless - https://s2maps.eu by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2016), licensed CC BY 4.0.
Elevation and sea depth: Terrain Tiles on AWS (Mapzen terrarium; SRTM, GMTED, ETOPO1 and other open sources).

Sound: title stings in sfx/ are original, made for KHORA.
